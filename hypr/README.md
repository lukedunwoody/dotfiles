# Hypr

The `hypr` folder contains my `hyprpaper` and `hyprland` configs.

## Features

- Hue shifted and background blurred wallpaper from Unsplash
- Custom app launcher using `kitty` and window rules.
- Record toggle script
- Workspace switching with controller using `antimicrox`
- Screen capturing with `swappy`

## Getting Started

### Step 1: Devices

Go to `devices.lua` and add any monitors and input devices you plan to connect.

### Step 2: Desktops

Feel free to delete `laptop.lua` if you are using a desktop computer without the revalant inputs.

### Step 3: Link with Stow

From the repository root, run this command:

```bash
stow hypr
```
